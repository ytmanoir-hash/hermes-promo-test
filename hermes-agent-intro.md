# Hermes Agent - AI Infrastructure for Autonomous Operations

> An open-source AI agent infrastructure built for autonomous operations.

## Key Features
- **Multi-provider routing** - Intelligent model selection with automatic failover
- **Cron jobs** - Scheduled tasks with persistent state and Telegram notifications
- **Web automation** - Full browser automation via Playwright
- **Zero-cost scaling** - Optimized for free tier resources

## Why Build This?
Most AI agents are just chat wrappers. Hermes is an **autonomous operator** - it runs while you sleep, monitors systems, publishes content, and executes workflows without human intervention.

Built with TypeScript, open-sourced under MIT.
